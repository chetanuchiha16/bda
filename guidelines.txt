Assignment Theme 1 — MongoDB Big Data Processing & Analytics
• Document Data Ingestion: Store, index, and organize large-scale
structured/unstructured dataset into MongoDB collections.
• Aggregation Pipelines: Implement queries using $match, $group, $project,
$unwind, and $facet to perform analytical processing.
• Query Performance Profiling: Evaluate index performance and execution
speed using .explain("executionStats").

Assignment Theme 2 — Hadoop File Management & MapReduce
Analytics
• HDFS Operations: Install Hadoop and perform distributed file
management tasks:
• Creating directories and adding files (hdfs dfs -mkdir, hdfs dfs -put).
• Retrieving files (hdfs dfs -get, hdfs dfs -cat).
• Deleting files and directories (hdfs dfs -rm -r).
• MapReduce Execution: Program, compile, and execute MapReduce jobs
(Java or Python Streaming) on YARN to analyze the stored dataset.

Assignment Theme 3 — Pig Latin & Hive RCFile Performance
Analytics
• Data Transformation in Pig: Write a Pig Latin script to load, clean, and
filter the raw structured dataset.
• Hive Export & RCFile Format: Ingest the filtered data into Apache Hive
and store it using the RCFile (Record Columnar File) format alongside a
Standard Text format table.
• Performance Analysis: Execute identical analytical Hive queries (HQL)
against both formats to analyze and report performance differences in query
execution time and disk compression.

Track B – Part 2 – 10 Marks
• Groups taking Track B must complete one practical extension (or a custom
extension approved for their dataset statement):
• Sample Option 1 (Cross-System Hybrid Integration): Connect MongoDB
directly to Hadoop/Hive using native connectors to perform cross-platform
batch querying and real-time processing.
• Sample Option 2 (Performance Profiling & System Stress Testing):
Benchmark execution times and resource consumption (CPU, I/O,
Memory) across MapReduce, Pig, and Hive under varying cluster
parameters (e.g., HDFS split sizes, block sizes, mapper/reducer counts).
• Sample Option 3 (Web Dashboard & Visualization (Flask / UI) –
Building a front end or a data visualisation dashboard or using python flask.
